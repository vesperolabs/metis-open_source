# Code of Conduct

Metis is built for a sensitive, high-conflict domain. Project discussions must remain respectful, factual and protective of personal privacy.

## Expected behavior

- Discuss ideas and code without attacking people.
- Use fictional, minimized examples.
- Respect different family structures, genders and parental roles.
- Accept safety and privacy review as part of normal engineering work.
- Give constructive feedback and assume good faith while still checking claims against evidence.

## Unacceptable behavior

- Publishing identifying or private case information.
- Harassment, threats, discriminatory language or personal attacks.
- Using project discussions to diagnose, shame or assign blame to people in a family dispute.
- Presenting project output as professional legal advice.

Maintainers may edit or remove contributions and restrict participation when needed to protect contributors, users or third parties.
